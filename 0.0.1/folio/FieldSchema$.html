Build a FieldSchema from just the forward FIELD => String mapping. The reverse fromName is derived by enumerating the enum cases at compile time via scala.deriving.Mirror.SumOf and matching against the supplied mapping.

Only works for enums whose cases are all singletons (no parameters). For richer cases, implement FieldSchema directly.
